# METFNet

Project repository for **HRRP Target Recognition Based on Manifold-Enhanced Tangent-Space Fusion Network**.

**Authors:** Ren Qi, Xueqian Wang, Jianghong Han, and Gang Li.

## Overview

METFNet is a manifold-enhanced tangent-space fusion network for high resolution range profile (HRRP) target recognition. It constructs covariance descriptors from multi-scale HRRP feature maps and learns compact symmetric positive definite (SPD) manifold representations. Tangent-space features from the manifold streams are fused with Euclidean features for target recognition.
